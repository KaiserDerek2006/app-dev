# My Favorite Series: Stranger Things

## About
*Stranger Things* is a **sci-fi horror** series set in the 1980s. A group of friends in a small town uncover secrets, strange powers, and a dangerous world called the Upside Down.

## Favorite Characters
- Eleven
- Mike
- Dustin
- Steve

## Why I Love It
1. Exciting and mysterious plot
2. Great 80s music and style
3. *Strong* friendships between the characters
